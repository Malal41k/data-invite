# Сайт-приглашение на свидание 💌

Это мой первый полноценный pet-проект на языке **Go**. Сайт предлагает девушке пойти на свидание, позволяет выбрать дату и ресторан, а её ответ сохраняет в базу данных.

## 🛠 Технологии
*   **Go (Golang)** — серверная логика, HTTP-маршруты (без фреймворков).
*   **PostgreSQL** — база данных для хранения ответов (работа через пакет `pgx`).
*   **HTML / CSS / JS** — интерфейс и анимации (кнопка «Нет» убегает от курсора).

## 🚀 Как запустить локально
1. Установите PostgreSQL и создайте базу `invite_db`.
2. Создайте таблицу `answers` (SQL-скрипт в коде).
3. Выполните `go mod download` для загрузки зависимостей.
4. Запустите сервер: `go run main.go`
5. Откройте `http://localhost:8080` в браузере.
